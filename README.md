# PS Reinigung – Demo Onlineshop

Modern German B2B demo shop for Perfect Solution GmbH / PS Reinigung.

## Demo

Production target: https://ps-reinigung.smarbiz.sbs

## Scope

- Responsive German storefront
- Product categories and search/filter
- Demo product catalog based on the existing PS Reinigung assortment
- Functional cart drawer
- Clickable demo checkout
- B2B quote-request flow
- Company/contact content
- No real payment or order processing in demo mode

## Deployment

GitHub Actions deploys the static demo to the server using the existing `HOST` and `PASS` repository secrets.
